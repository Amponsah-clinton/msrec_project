{% comment %} The Secretariat sidebar, in one place. It used to be copy-pasted into all eight Secretariat templates (~177 lines each). They had already drifted into three different sidebars: Messages was missing the Deviations link and had a different set of Meetings sublinks, Application Detail highlighted nothing at all, and Messages marked its own sublink active inside a group it left collapsed -- so on those pages the sidebar either changed shape or showed no "you are here" at all. Active state is derived from the resolved URL name rather than each page hardcoding `active` on its own entry, so a new Secretariat page gets its highlight (and its parent group opened) by being routed, not by remembering to edit its copy of the markup. Destinations that aren't built yet render as non-interactive `.nav-upcoming` rows with a "Soon" chip instead of `href="#"` links.
