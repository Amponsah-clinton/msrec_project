How Verification Works

Three steps to a verified answer

Every approval issued by MSREC is registered with a unique number, verification code and QR code the moment it is granted.

01

Enter or scan

Provide the approval number, verification code, or scan the QR code printed on the certificate.

02

We check the registry

The code is matched against MSREC's official record of every approval ever issued, amended or withdrawn.

03

See the current status

You get the live status — approved, conditional, expired or suspended — not just a copy of the original letter.

Result doesn't look right?

If a certificate you were shown doesn't match what appears here, or a code cannot be found, do not treat the approval as valid. Report it to the Secretariat so it can be investigated.
